# Rules Lab v0

本文件记录网页原型中的可配置实验假设，不代表 ProjectC 最终规则。

## 当前输入

- 棋盘：10 × 10，Ground 与 Sky 共用坐标。
- 基础 AP：3；上回合最多继承 1 AP，仅持续至下一回合。
- 玩家基础行动：移动、剑攻击、出牌。
- 玩家装备：剑、普通衣服、普通鞋。
- 敌人：灵活的追猎者、强壮的精英守卫。
- NPC：初始体温 -3，恢复到 0 后开始跟随玩家。
- Session：温暖 NPC、处理精英守卫、护送 NPC 返回 Shelter。

## 可切换结算顺序

1. 玩家行动后局部反应 → 敌人行动后局部反应 → 一次全局环境。
2. 玩家 → 全局环境 → 敌人。
3. 玩家 → 全局环境 → 敌人 → 全局环境。

玩家行动产生的局部反应当前即时执行；其余阶段通过“推进阶段”按钮单步观察。

## 环境规则 v0

1. 普通卡牌只能把目标 Cell 温度修改到 -2 ~ +2；结构支持 -3 ~ +3。
2. Water 在 Ground 温度 ≤ -1 时变为 Ice；Ice 在温度 ≥ +1 时变回 Water。
3. Grass 在 Ground 温度达到 +2 且不为 Wet 时变为 Fire。
4. Water 在 Ground 温度达到 +1 且对应 Sky 为空时形成 Cloud。
5. Ground 与 Sky 温差达到 2 时，Sky 温度向 Ground 靠近 1 格。
6. 相邻 Sky 温差达到 2 时，从高温格向低温格生成风。
7. Cloud 在全局环境阶段沿风向移动 1 格；持续两次全局阶段后生成 Rain intent。
8. Rain 在下一次全局环境阶段生效：提高湿度、熄灭 Fire、使 Ground 温度向 0 回落，并消耗 Cloud。
9. Actor 在热交换阶段受到所在 Ground Cell 单向影响；普通被动过程不反向改变 Cell。
10. Actor 体温达到 -3 / +3 时受到 1 点环境伤害。

- 降温
- 紧握
- 热势斩
- 冷锋
- 推斩
- 穿刺
- 放血
- 格挡
- 回火

卡牌文本与费用仅用于建立体验标尺，下一轮应重点检查它们是否侵占环境自动演化、是否过度复合以及是否真正形成温度与战斗取舍。

## 第一轮建议观察

- 三种结算顺序中，哪一种最容易预判又不会让环境失去回应速度。
- 玩家是否愿意保留 1 AP，而不是总在当前回合花完。
- 天空温差、风、云和雨是否容易读懂。
- 追猎者与精英是否给环境布局留下合理空间。
- NPC 从 -3 恢复到 0 的过程是否过慢或过快。
- 首批卡牌中，哪些只是更强的基础攻击，哪些真正产生了环境策略。
